ORDER LINK — DEMO

1. Buka index.html di browser.
2. Edit ADMIN_WA di dalam kode menjadi nomor WhatsApp admin.
   Format: 628xxxxxxxxxx (tanpa + dan tanpa spasi).
3. Edit nama usaha, layanan, dan harga di bagian HTML.
4. Untuk online, upload folder ini ke hosting statis seperti Vercel/Netlify/GitHub Pages.

Alur:
Customer -> isi form -> klik Pesan via WhatsApp -> WhatsApp admin terbuka dengan format order otomatis.

Versi ini belum memakai database/login/payment gateway. Cocok untuk demo MVP.
